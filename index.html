P.02

Autonomous Research & Report Agent

Multi-agent LangGraph pipeline with claim-checking Critic and human-in-the-loop audit logs.
THE PROBLEM
Single-prompt research agents suffer from cross-topic reasoning drift, tool-call hallucinations, and unverified source claims during long execution workflows.
WHAT I BUILT
Designed a 4-agent workflow (Planner → Researcher → Writer → Critic) in LangGraph where the Critic validates every claim against raw Tavily web sources. Added human-in-the-loop approval gates, budget controls, and full decision audit logging running on Groq free-tier LLMs.

VisionInspect AI

Deep learning defect detection platform with layer fine-tuning & class imbalance correction.
THE PROBLEM
Industrial visual inspection datasets exhibit severe class imbalance (majority normal samples), causing standard classifiers to achieve high accuracy while failing on rare defective parts (only 36% recall).
WHAT I BUILT
Built a ResNet50 transfer-learning defect detection pipeline across 3 MVTec AD categories, using weighted sampling and gradient clipping to boost minority-class recall from 36% to 91% (87–98% test accuracy). Shipped as a reproducible Dockerized FastAPI service.
